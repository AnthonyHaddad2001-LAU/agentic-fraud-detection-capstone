1. Clone repository: git clone https://github.com/AnthonyHaddad2001-LAU/agentic-fraud-detection-capstone
2. Set up virtual environment: python3 -m venv venv && source venv/bin/activate
3. Install dependencies: pip install -r requirements.txt
4. Pull local LLM model: ollama pull llama3.1
5. Run system demonstration: python main.py
